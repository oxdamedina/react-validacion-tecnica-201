# J03-02 — HOC

[← Página anterior](J03-01-contexto.md) · [Siguiente página →](J03-03-memo.md)

Un HOC es una función. Recibe un componente y devuelve otro. `conRevisor` lee el contexto y pasa `revisor` como prop. `App` sigue sin escribir `revisor=` en la etiqueta. `memo`, en la página siguiente, es un HOC que ya trae React.

## Demostración

### Objetivo

Sacar `useSesion` de `Tarjeta`. Una función recibe el componente y le pasa `revisor` como prop.

### Código de partida

Las seis fichas dicen «Revisor: Ana». Una caja cambia el nombre. `Tarjeta` llama a `useSesion()` y no recibe `revisor` por props. Pega estos archivos si no es así.

`bandeja/src/contexto/Sesion.tsx`

```tsx
import { createContext, useContext, useState, type ReactNode } from "react"

interface Sesion {
  revisor: string
  setRevisor: (nombre: string) => void
}

const SesionContexto = createContext<Sesion | null>(null)

export function SesionProveedor({ children }: { children: ReactNode }) {
  const [revisor, setRevisor] = useState("Ana")
  return (
    <SesionContexto.Provider value={{ revisor, setRevisor }}>
      {children}
    </SesionContexto.Provider>
  )
}

export function useSesion(): Sesion {
  const sesion = useContext(SesionContexto)
  if (!sesion) throw new Error("useSesion fuera del proveedor")
  return sesion
}
```

En `main.tsx`, `<SesionProveedor>` envuelve a `<App />`.

`bandeja/src/App.tsx`

```tsx
import { useState } from "react"
import { entregables } from "./datos"
import type { Entregable } from "./modelo"
import Tarjeta from "./componentes/Tarjeta"
import { useSesion } from "./contexto/Sesion"

export default function App() {
  const [texto, setTexto] = useState("")
  const [items, setItems] = useState<Entregable[]>(entregables)
  const { revisor, setRevisor } = useSesion()

  const visibles = items.filter((item) => {
    const blob = `${item.titulo} ${item.proveedor} ${item.id}`.toLowerCase()
    return blob.includes(texto.toLowerCase())
  })

  function marcar(id: string): void {
    setItems((lista) =>
      lista.map((item) =>
        item.id === id ? { ...item, estado: "revisado" } : item,
      ),
    )
  }

  return (
    <main>
      <h1>Bandeja de entregables</h1>
      <label htmlFor="revisor">Revisor</label>
      <input
        id="revisor"
        value={revisor}
        onChange={(evento) => setRevisor(evento.target.value)}
      />
      <label htmlFor="filtro">Buscar</label>
      <input
        id="filtro"
        value={texto}
        onChange={(evento) => setTexto(evento.target.value)}
      />
      {visibles.length === 0 ? <p>Ningún entregable coincide.</p> : null}
      <ul className="lista">
        {visibles.map((item) => (
          <li key={item.id}>
            <Tarjeta item={item} alMarcar={marcar} />
          </li>
        ))}
      </ul>
    </main>
  )
}
```

`bandeja/src/componentes/Tarjeta.tsx`

```tsx
import type { Entregable } from "../modelo"
import { useSesion } from "../contexto/Sesion"

interface TarjetaProps {
  item: Entregable
  textoBoton?: string
  alMarcar: (id: string) => void
}

export default function Tarjeta({
  item,
  textoBoton = "Anotar",
  alMarcar,
}: TarjetaProps) {
  const { revisor } = useSesion()
  return (
    <article>
      <p>{item.titulo}</p>
      <p>
        {item.id} · {item.proveedor}
      </p>
      <p>Revisor: {revisor}</p>
      <p className={`estado ${item.estado}`}>{item.estado}</p>
      {item.estado === "pendiente" ? <p>Falta revisión</p> : null}
      <button type="button" onClick={() => alMarcar(item.id)}>
        {item.estado === "revisado" ? "Hecho" : textoBoton} {item.id}
      </button>
    </article>
  )
}
```

### 1 — La función que envuelve

**Dónde:** archivo nuevo `bandeja/src/hoc/conRevisor.tsx`, y `Tarjeta.tsx`.

**Qué haces:**

1. Crea el archivo del HOC y pega esto.
2. En `Tarjeta`, `revisor` pasa a ser prop. Quita `useSesion` de la ficha.
3. La última línea del archivo deja de exportar la función a pelo.
4. Guarda. Escribe `Luis` en la caja.

```tsx
import type { ComponentType } from "react"
import { useSesion } from "../contexto/Sesion"

export function conRevisor<P extends { revisor: string }>(
  Componente: ComponentType<P>,
) {
  function Envuelto(props: Omit<P, "revisor">) {
    const { revisor } = useSesion()
    const completas = { ...props, revisor } as P
    return <Componente {...completas} />
  }
  return Envuelto
}
```

En `Tarjeta.tsx`, el import de `useSesion` se sustituye por este:

```tsx
import { conRevisor } from "../hoc/conRevisor"
```

La interfaz y la función quedan así. El `return` de la ficha no se toca: sigue pintando `{revisor}`.

```tsx
interface TarjetaProps {
  item: Entregable
  textoBoton?: string
  alMarcar: (id: string) => void
  revisor: string
}

function Tarjeta({
  item,
  textoBoton = "Anotar",
  alMarcar,
  revisor,
}: TarjetaProps) {
```

Y el archivo termina así, sin `export default function`:

```tsx
export default conRevisor(Tarjeta)
```

En `App`, la etiqueta sigue siendo `<Tarjeta item={item} alMarcar={marcar} />`. No le pases `revisor`.

**Experimento:** cambia la última línea a `export default Tarjeta`. Lee Problems. Vuelve a `export default conRevisor(Tarjeta)`.

→ Con el HOC, las seis fichas siguen en «Revisor: Ana» y `Luis` las cambia todas. `App` no escribe `revisor=`. Sin el HOC, Problems pide esa prop en cada `<Tarjeta>`.

**Validación:**

- `useSesion` está en `conRevisor.tsx`, no en `Tarjeta.tsx`.
- Problems vacío con `export default conRevisor(Tarjeta)`.
- El filtro sigue respondiendo.

## Comprueba tu entendimiento

**Qué devuelve un HOC**
`conRevisor` no pinta la ficha. Devuelve `Envuelto`.
→ `Envuelto` lee el contexto y llama a `Tarjeta` con la prop ya puesta. `memo`, en la página siguiente, es un HOC que ya trae React: también recibe un componente y devuelve otro.

## Reto

### 1 — Llamarlo como componente

En `App`, cambia `<Tarjeta item={item} alMarcar={marcar} />` por `<conRevisor />`.
→ Problems. Un HOC se llama como función, con el componente dentro: `conRevisor(Tarjeta)`. Restaura la etiqueta `<Tarjeta>`.

## Errores frecuentes

| Síntoma | Causa probable | Cómo arreglarlo |
|---------|----------------|-----------------|
| Falta `revisor` en `<Tarjeta>` | Exportaste `Tarjeta` sin envolverla | `export default conRevisor(Tarjeta)` |
| `useSesion fuera del proveedor` | `Envuelto` quedó fuera de `SesionProveedor` | El proveedor sigue envolviendo `<App />` en `main.tsx` |
| El nombre no cambia | La ficha pinta un texto fijo | El párrafo sigue siendo `Revisor: {revisor}` |

## Laboratorio

La demostración inyectó el revisor con `conRevisor`. Aquí el HOC no lee datos: envuelve la ficha con una sombra.

### Objetivo

`conSombra` recibe `Tarjeta` y devuelve un componente con `box-shadow`. No usa contexto.

### Código de partida

Parte de `export default function Tarjeta`. Si la demostración dejó `export default conRevisor(Tarjeta)`, vuelve a exportar la función para este ejercicio. El botón sigue llamando a `alMarcar`. El párrafo del revisor puede quedarse o quitarse: la sombra no lo usa.

### Qué haces

1. Crea `bandeja/src/hoc/conSombra.tsx`.
2. La última línea de `Tarjeta.tsx` pasa a `export default conSombra(Tarjeta)`.
3. Recarga. Cada ficha tiene sombra.
4. Cambia un momento el export a `Tarjeta` sin envolver. La sombra se va. Restaura `conSombra(Tarjeta)`.

```tsx
import type { ComponentType } from "react"

export function conSombra<P extends object>(Componente: ComponentType<P>) {
  function ConSombra(props: P) {
    return (
      <div style={{ boxShadow: "0 8px 24px #0003", borderRadius: 12, padding: 12 }}>
        <Componente {...props} />
      </div>
    )
  }
  return ConSombra
}
```

```tsx
import { conSombra } from "../hoc/conSombra"
```

```tsx
export default conSombra(Tarjeta)
```

→ Hay sombra en las seis fichas. `conSombra.tsx` no importa `useSesion` ni `revisor`. `App` no pasa ninguna prop de estilo.
